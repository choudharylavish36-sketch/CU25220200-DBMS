Q25. Perform a complete sequence of INSERT, UPDATE and DELETE operations on a Student table and display the table after each operation.
Step 1: Create the Student table
CREATE TABLE Student_DML (
    Student_ID INT PRIMARY KEY,
    Name VARCHAR(50),
    Age INT,
    Course VARCHAR(50),
    City VARCHAR(50)
);
Step 2: Insert records
INSERT INTO Student_DML
VALUES
(1, 'Rahul', 20, 'BCA', 'Delhi'),

Step 3: Display the table
SELECT * FROM Student_DML;
Step 4: Update a record
UPDATE Student_DML
SET City = 'Mumbai'
WHERE Student_ID = 1;
